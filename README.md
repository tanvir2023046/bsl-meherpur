# বাংলাদেশ ছাত্রলীগ — মেহেরপুর জেলা শাখা
## CV বিল্ডার ও সাংগঠনিক তথ্য ব্যবস্থাপনা সিস্টেম (Render + Supabase)

ইন্টারনেটে চালানোর উপযোগী সম্পূর্ণ প্যাকেজ — Node.js + Express + PostgreSQL (Supabase)।
`DATABASE_URL` সেট না থাকলে আগের মতো লোকাল SQLite ফাইলেও চলে।

### যা যা আছে
- ধাপে ধাপে বাংলা CV বিল্ডার (লাইভ প্রিভিউসহ)
- ছবি ও স্বাক্ষর আপলোড + ক্রপ
- ডাইনামিক A4 প্রিন্ট/PDF (তথ্য অনুযায়ী পৃষ্ঠা বাড়বে)
- যাচাইকৃত মেহেরপুর প্রশাসনিক কাঠামো (৩ উপজেলা, ২ পৌরসভা, ২০ ইউনিয়ন, ১৮ ওয়ার্ড)
- ড্যাশবোর্ড, ডিরেক্টরি, সার্চ ও ফিল্টার
- ভূমিকা-ভিত্তিক নিরাপত্তা (৮টি ভূমিকা; NID ও ফোন নম্বর সার্ভার-সাইডে সুরক্ষিত)
- খসড়া অটো-সেভ, বাংলা ভ্যালিডেশন মেসেজ

### 📱 মোবাইল থেকে GitHub-এ আপলোড (ফ্ল্যাট ভার্সন)

এই প্যাকেজটি বিশেষভাবে ফ্ল্যাট রাখা হয়েছে — সব ফাইল একই লেভেলে, কোনো ফোল্ডার নেই। Android-এর ফাইল পিকারে ফোল্ডার সিলেক্ট করা যায় না বলে:

১. জিপটি আনজিপ করুন — ভেতরের **সব ফাইল একসাথে সিলেক্ট** করুন (কোনো ফোল্ডার নয়)
২. GitHub-এ রিপোজিটরি খুলে **Add file → Upload files**-এ সব ফাইল ড্রপ/সিলেক্ট করুন
৩. **Commit changes** চাপুন — ব্যস, কোনো `public/` ফোল্ডার লাগবে না, `index.html` সহ সবকিছু রিপোজিটরির রুটেই থাকবে

> নোট: `node_modules/`, `uploads/` ও `data/` আপলোড করবেন না — সার্ভার চালুর সময় এগুলো নিজে নিজে তৈরি হয়ে যাবে, আর খালি ডাটাবেজ পেলে সিডও নিজে নিজে হয়ে যাবে।

## ক) Supabase-এ ফ্রি ডাটাবেজ তৈরি

১. https://supabase.com → **Start your project** → ফ্রি অ্যাকাউন্ট খুলুন
২. **New project** → নাম দিন (যেমন `bcl-meherpur`), পাসওয়ার্ড দিন, Region: **Singapore** (বাংলাদেশের কাছাকাছি) বেছে **Create** চাপুন
৩. প্রজেক্ট তৈরি হলে বাম মেনু থেকে **Project Settings (⚙️) → Database**
৪. **Connection string** অংশে **URI** ট্যাবে যান — **Connection pooling** সেকশনের string-টি কপি করুন
   (এটি `postgres://postgres.[ref]:[পাসওয়ার্ড]@aws-...pooler.supabase.com:6543/postgres` আকারের হয় — Render থেকে এটাই ব্যবহার করবেন)
   ⚠️ `[YOUR-PASSWORD]`-এর জায়গায় ২নং ধাপের ডাটাবেজ পাসওয়ার্ড বসান

## খ) কোড GitHub-এ তুলুন

১. https://github.com → **New repository** (নাম যেমন `bcl-meherpur-cv`), **Create**
২. এই ফোল্ডারে টার্মিনাল খুলে:
```
git init
git add .
git commit -m "BCL Meherpur CV system"
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/bcl-meherpur-cv.git
git push -u origin main
```

## গ) Render-এ ডিপ্লয় (ফ্রি)

১. https://render.com → GitHub দিয়ে সাইন আপ/লগইন
২. **New + → Blueprint** → আপনার রিপোজিটরি সিলেক্ট করুন (`render.yaml` নিজে থেকেই ধরা পড়বে)
৩. **Apply** চাপলে `DATABASE_URL` চাইবে — ক) ধাপে কপি করা Supabase pooler URL-টি বসান
৪. `SESSION_SECRET` নিজে থেকেই তৈরি হয়ে যাবে
৫. **Deploy** — ২–৪ মিনিটে সার্ভার চালু হবে। প্রথম চালুতেই ডাটাবেজ খালি দেখে অ্যাপ নিজে থেকে ৪৪টি ইউনিট, ৮টি ভূমিকা, ১৩টি পদ ও অ্যাডমিন অ্যাকাউন্ট তৈরি করে নেবে

## ঘ) প্রথম লগইন

- Render-এর দেওয়া URL খুলুন (যেমন `https://bcl-meherpur-cv-system.onrender.com`)
- ব্যবহারকারীর নাম: `admin` / পাসওয়ার্ড: `admin123`
- ⚠️ **প্রথমেই** অ্যাডমিন প্যানেল → ব্যবহারকারী থেকে পাসওয়ার্ড বদলে নিন

> 💡 Render ফ্রি প্ল্যানে ১৫ মিনিট নিষ্ক্রিয় থাকলে সার্ভার "ঘুমিয়ে" যায়; প্রথম ভিজিটে ৩০–৬০ সেকেন্ড লাগতে পারে। ডাটা Supabase-এ থাকে, তাই কখনো হারাবে না।

## লোকাল মোড (আগের মতো, SQLite)

`DATABASE_URL` সেট না করলে অ্যাপ লোকাল `data/app.db` ফাইলে চলে:

```
npm install
npm start
```
ব্রাউজার: **http://localhost:3000**

ডাটাবেজ খালি থাকলে প্রথম চালুতেই সিড হয়ে যাবে (`npm run seed` আলাদা চালানোর দরকার নেই, তবে চাইলে চালাতে পারেন)।

## ডাটাবেজ ব্যাকআপ
- **Supabase মোডে:** Supabase Dashboard → Database → Backups (ফ্রি প্ল্যানে দৈনিক ব্যাকআপ)
- **লোকাল মোডে:** সার্ভার বন্ধ করে `data/app.db` ফাইলটি কপি করুন

## ⚠️ জানা সীমাবদ্ধতা
- আপলোড করা ছবি/স্বাক্ষর `uploads/` ফোল্ডারে থাকে। Render ফ্রি প্ল্যানে সার্ভার রিস্টার্ট হলে এই ফাইলগুলো মুছে যেতে পারে (ডাটাবেজের তথ্য নিরাপদ থাকে)। স্থায়ী ছবি সংরক্ষণ দরকার হলে পরে object storage (যেমন Cloudinary/S3) যোগ করা যাবে।

## ফোল্ডার কাঠামো
```
├── server.js          # Express ব্যাকএন্ড (API + অথ + RBAC)
├── db.js              # ডুয়াল-ড্রাইভার DB স্তর (PostgreSQL ↔ SQLite)
├── seed.js            # ডাটাবেজ তৈরি ও যাচাইকৃত তথ্য সিড (উভয় DB-তে চলে)
├── schema.sql         # SQLite স্কিমা
├── schema.pg.sql      # PostgreSQL স্কিমা
├── render.yaml        # Render Blueprint
├── package.json
├── data/app.db        # লোকাল মোডের SQLite ডাটাবেজ
├── uploads/           # আপলোড করা ছবি/স্বাক্ষর
└── public/            # ফ্রন্টএন্ড (index.html, css/, js/)
```
